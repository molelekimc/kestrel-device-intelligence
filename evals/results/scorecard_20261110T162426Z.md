## 4. Pipeline fixes found by evaluation

Evals were not changed to make them pass; defects were fixed in the pipeline.

- **Found by:** silver validation: claimed_not_observed precision
  - **Defect:** Rollout reconciliation compared a device's last telemetry date with the tracker's scheduled date. Upgrades land a few days after schedule and only show at the next boot, so 222 of 245 'claimed but not observed' devices had in fact migrated after their last telemetry in the window (precision 9%).
  - **Fix:** pipeline/gold.py now derives the scheduled-to-first-25H2 lag from the data (95th percentile, 8 days) and only calls a Done claim contradicted when telemetry continues past schedule + lag on the old build; earlier cases are 'unverifiable'.
  - **Result:** claimed_not_observed precision 100% (18/18); 18 of 24 true failed-but-Done devices caught, the other 6 correctly labelled unverifiable.
- **Found by:** end-to-end demo test before Phase 5
  - **Defect:** The os_build rejection message echoed the normalised value ('23h2') instead of the caller's input.
  - **Fix:** mcp_server/guardrails.py echoes the original value.
  - **Result:** Regression test added.
- **Found by:** business evidence checks while building Phase 6 (change correlation)
  - **Defect:** Change evidence ranked every metric for every change, so changes in nearby weeks inherited each other's effects (the shop-floor agent rollout 'explained' the MES 4.2.0 crash spike; the HP Mini exclusion 'reduced' MES crashes), and a break and its fix in the same week looked identical.
  - **Fix:** pipeline/gold_business.py judges each change only on metrics its type can move, names the app version or bug check code carrying the shift and the change that deployed it (downgrading shifts explained by another change), lists competing changes, and measures coverage on day windows until a rollout ends.
  - **Result:** MES 4.2.0, the Durban proxy change and its fix, and the hotfix are strong; the Defender red herring is weak and 'explained by CHG0041031'; the agent rollout is moderate on coverage.
